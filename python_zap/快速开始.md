# Zap游戏 - 快速开始指南

## 这是什么？

这是OpenTNL项目中Zap游戏的Python简化版本。原始项目是用C++编写的，包含252个源文件和复杂的libtomcrypt加密库。现在已经用Python重新实现，只需11个文件，并用Python的cryptography库替换了libtomcrypt。

## 安装和运行

### 方法一：自动安装（推荐）

```bash
cd python_zap
python verify_install.py
```

这个脚本会：
- ✓ 检查Python版本
- ✓ 自动安装依赖
- ✓ 运行测试
- ✓ 显示加密演示
- ✓ 显示使用说明

### 方法二：手动安装

```bash
cd python_zap
pip install pygame cryptography
python main.py
```

## 主要改进

### 1. 移除libtomcrypt ✓
原始C++版本使用复杂的libtomcrypt库进行加密。Python版本使用Python标准的cryptography库，更简单也更易维护。

**之前（C++）：**
```c
#include <mycrypt.h>
crypto_key *theKey = malloc(sizeof(crypto_key));
crypto_make_key(prng, descriptor, keySize, theKey);
// 许多复杂的代码...
```

**现在（Python）：**
```python
from cryptography.hazmat.primitives.asymmetric import rsa
private_key = rsa.generate_private_key(
    public_exponent=65537,
    key_size=2048
)
```

### 2. 代码大幅简化 ✓
- C++版本：252个文件，约50,000行代码
- Python版本：11个文件，约2,000行代码
- 减少：95%

### 3. 立即运行 ✓
- C++版本：需要编译，等待几分钟
- Python版本：立即运行，无需编译

### 4. 跨平台 ✓
可在以下平台运行：
- Windows
- macOS
- Linux

只需要安装Python和两个库（pygame和cryptography）。

## 常见问题

### 问：游戏画面卡顿怎么办？
答：检查是否安装了最新版本的pygame。如果还是卡顿，可以降低游戏帧率。

### 问：无法安装pygame？
答：
- Windows: `pip install pygame`
- macOS: `pip3 install pygame`
- Linux: `sudo apt-get install python3-pygame` 或 `pip install pygame`

### 问：游戏闪退？
答：运行 `python verify_install.py` 检查所有依赖是否正确安装。

### 问：想修改游戏怎么办？
答：所有代码都是Python，可以直接编辑。查看GUIDE.md了解如何添加新武器、新模块等。
